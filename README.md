# Цифровой Двойник Карьера (ВКР: Специальность ИИ и машинное зрение)

Программный комплекс мониторинга физического макета карьера и техники в реальном времени с использованием компьютерного зрения, моделей искусственного интеллекта и фильтрации Калмана.

---

## Архитектура системы

- **Ядро и состояние (`core/`):**
  - `state_manager.py` — Менеджер карьеров и единиц техники в оперативной памяти.
  - `fusion.py` — Трехмерный фильтр Калмана (KalmanFilter3D) для сглаживания координат $(X, Y, Z)$, подавления шумов оптического трекинга и расчета скорости.
  - `models.py` — Pydantic-модели валидации пространственных данных и телеметрии.

- **Компьютерное зрение и ИИ (`ai/`, `vision/`):**
  - `base_detector.py` — Единый абстрактный контракт (`BaseDetector`) для всех модулей детекции.
  - `aruco_detector.py` — Практический оптический детектор меток ArUco на OpenCV для лабораторного макета карьера (определение координат и угла курса).
  - `yolo_detector.py` — Модуль для подключения нейросетевых моделей детекции техники (YOLO OBB / ONNX Runtime).
  - `synthetic_generator.py` — Синтетический генератор макета карьера и динамики машинок (для отладки и демонстрации без подключенной физической камеры).
  - `camera_stream.py` — Многопоточный захват видеопотока с физической веб-камеры или генератора.

- **База данных (`database/`):**
  - SQLAlchemy ORM (`quarry_sites`, `quarry_vehicles`, `telemetry_logs`) с поддержкой неограниченного числа независимых карьеров (Multi-Quarry).

- **Сервер и Веб-интерфейс (`server/`, `web/`):**
  - FastAPI сервер, REST API, WebSocket для потоковой передачи телеметрии $(X, Y, Z)$ с частотой до 30 Гц.
  - MJPEG-видеотрансляция (`/video_feed`) с наложенной разметкой компьютерного зрения.
  - Диспетчерский веб-интерфейс: видеопоток с камеры, координатная сетка карьера с изогипсами уступов, динамические маркеры машинок с векторами направления и таблица телеметрии.

## Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск системы
```bash
python main.py
```

После запуска откройте в браузере:
- **Панель мониторинга:** [http://localhost:8000](http://localhost:8000)
- **Видеопоток с разметкой:** [http://localhost:8000/video_feed](http://localhost:8000/video_feed)
- **Swagger документация API:** [http://localhost:8000/docs](http://localhost:8000/docs)

### 3. Запуск тестов
```bash
python -m pytest tests/
```

## Конфигурация (`config/settings.py`)

- `DEMO_MODE = True`: автоматическая симуляция движения машинок по уступам макета карьера с реальными маркерами ArUco (удобно для отладки без камеры).
- `DEMO_MODE = False`: подключение к реальной камере на треноге (`CAMERA_SOURCE = 0` или RTSP ссылка).
